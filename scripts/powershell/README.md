# PowerShell 7 任务执行脚本

01–07 是按任务分开的固定入口，接收由 Python 编译的 `-ConfigPath`；`-ValidateOnly` 只校验，不创建任务。它们转交同目录的通用执行器，任务细节来自对应 Skill 合同。请通过 `run.py` 或 `runtime.dispatch` 调用，不要使用脚本默认的示例配置文件名执行真实想定。

| 脚本 | 对应 Skill | 区域或目标 |
| --- | --- | --- |
| `01-飞机战斗巡逻.ps1` | `air.combat_patrol` | 巡逻区外扩 100 公里生成独立警戒区；启用区外目标分析、武器射程内目标分析及 1/3 规则；单机编队；出航高度 3000 米、阵位高度 10000 米并回读确认 |
| `02-飞机对空打击.ps1` | `air.air_strike` | 当前空中接触目标 |
| `03-飞机对海打击.ps1` | `air.sea_strike` | 一个当前水面接触目标，同一任务至少两架不同飞机；创建前校验 |
| `04-飞机对地打击.ps1` | `air.land_strike` | 当前地面接触目标 |
| `05-空中预警.ps1` | `air.early_warning` | 预警机支援区域；固定出航 2000 米、阵位 10000 米、1/3 与加油周期选项；任务级雷达打开、干扰机/声纳静默并回读 |
| `06-舰艇海上巡逻.ps1` | `navy.sea_patrol` | 海上巡逻区外扩 100 公里生成独立警戒区；启用区外目标分析和武器射程内目标分析；航线可选 |
| `07-舰艇对海攻击.ps1` | `navy.sea_strike` | 当前水面接触目标 |
| `08-删除任务及对应区域.ps1` | 独立维护入口 | 删除指定任务；区域仅在满足安全条件时删除 |
| `09-电子干扰伴随.ps1` | 自动推演的独立控制入口 | 打击任务触发后请求干扰机起飞；升空后尾随并开启雷达/电子干扰；结束时关闭设备并请求返航 |
| `10-开局蓝方接战规则.ps1` | 推演方开局条令 | 设置蓝方 `General.ROE.ShootTourists=1`（可以与任何临机目标交战），回读确认；`-ValidateOnly` 只读检查 |
| `Invoke-MoziBlueMissionPlan.ps1` | 七类任务共用 | 校验配置，按顺序创建/更新区域、任务、规则、分配单元和目标，并回读报告 |

所有 POST 请求体由执行器以 UTF-8 字节发送。打击任务必须回读到目标、主攻单元和单机编队规模；飞机打击还须核对实际挂载。巡逻任务必须回读到不同的巡逻区与警戒区 GUID、警戒区参考点、区外与武器射程内目标分析开关；飞机巡逻还回读确认单机编队规模（FlightSize=1）。脚本报告和任务 GUID 位于 `runs/<批次>/reports/`。修改 API 调用顺序时检查 `tests/test_powershell_http_utf8.py` 和 `tests/test_script_skill_runtime.py`。

巡逻与打击任务固定设置任务级 General.ROE.ShootTourists=1（接战临机目标＝是）；打击任务另设置 EMCSetting.EMCON_AccordingSuperior=false、Radar=1、OECM=0、Sonar=0。两组分别写入并回读；预警任务保留独立电磁管控规则。

飞机对海打击的“至少两架”表示多架飞机共同分配给同一目标的同一任务。底层 FlightSize=1 保证奇数分配也能逐架出动，不保证精确同步起飞或同时到达；实际出动还取决于墨子的准备状态和任务调度。

打击任务先写入 StrikeMissionRules（FlightSize=1），再分配飞机和目标；实测墨子写入该规则会清空旧飞机分配。巡逻区与警戒区各有独立区域创建日志，更新任务后只清理已无任务引用的旧区域。
