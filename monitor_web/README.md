# Agent 监控网页

这是独立、只读的本地前端。运行根目录 `monitor_dashboard.py` 或双击 `启动Agent监控前端.cmd` 后，在 `http://127.0.0.1:8765/` 查看当前与历史 Agent 输入输出。页面不连接模型，也不创建墨子任务。

双击脚本优先使用系统可用的 `python`，没有时再尝试 `py -3`。若默认端口 8765 被占用或系统拒绝监听，程序会选一个空闲端口，终端显示并打开实际访问地址。手工指定 `--port` 时端口错误会直接报告，便于检查该端口。

| 代码/资源 | 作用 |
| --- | --- |
| `server.py` | 只监听 `127.0.0.1`，读取 `runs/agent_monitor/events.jsonl`，提供场次、分页事件与整场导出接口 |
| `index.html` | 页面结构：场次列表、统计、时间线和详情面板 |
| `app.js` | 每 2 秒增量读取、筛选、输入输出切换、历史翻页与导出交互 |
| `style.css` | 桌面与窄屏布局及视觉样式 |
| `__init__.py` | Python 包标记 |

`server.py` 的 `/api/sessions` 只增量索引新增日志；`/api/events` 按字节游标读取，避免每次刷新扫描全量历史。`/api/export` 导出所选场次全部 JSONL。日志由 `agents/monitor_log.py` 写入；若推演程序还在使用旧代码，先重启 `run.py` 才会出现新的完整记录。
