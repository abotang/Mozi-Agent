# `air.air_strike`：飞机对空打击

由空军 Agent 选择蓝方非预警飞机、可选护航机，以及**当前** `contacts.air` 中的目标接触 GUID。脚本创建 Strike/Air 任务并绑定目标；没有有效目标不能创建，也不填写巡逻区。

| 本目录文件 | 作用 |
| --- | --- |
| `skill.json` | 机器合同：目标类别、护航能力、脚本映射和参数限制 |
| `SKILL.md` | 当前接触目标、主攻/护航单位等使用规则 |
| `README.md` | 文件定位与执行链说明 |

执行链：规划校验 → 配置编译 → `scripts/powershell/02-飞机对空打击.ps1` → 分配飞机/目标 → 回读目标列表。历史接触 GUID 只供态势分析，不能作为本轮新打击目标。
