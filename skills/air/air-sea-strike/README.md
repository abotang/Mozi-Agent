# `air.sea_strike`：飞机对海打击

由空军 Agent 选择蓝方飞机及**当前** `contacts.sea` 中的水面接触目标；已知的反舰挂载 GUID 才填写。脚本创建航空对海 Strike 任务、绑定目标并分配飞机，不创建巡逻区域。

| 本目录文件 | 作用 |
| --- | --- |
| `skill.json` | 机器合同：水面目标、可用挂载及固定脚本 |
| `SKILL.md` | 目标来源、挂载和必填参数说明 |
| `README.md` | 文件定位与执行链说明 |

执行链：规划校验 → 配置编译 → `scripts/powershell/03-飞机对海打击.ps1` → 墨子任务与目标回读。没有当前水面接触时不调用该 Skill。
