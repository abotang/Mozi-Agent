# `navy.sea_patrol`：舰艇海上巡逻

海军 Agent 选蓝方水面舰艇并划定多边形巡逻区；可附出航航线和区内航线，但航线不能代替区域。`rules/navy_patrol.py` 只在想定开局开放新建，后续轮次不重复创建巡逻任务。

| 本目录文件 | 作用 |
| --- | --- |
| `skill.json` | 机器合同：Ship 单元、区域、可选航线和脚本映射 |
| `SKILL.md` | 区域与航线的区别、开局限制及参数要求 |
| `README.md` | 文件定位与执行链说明 |

执行链：开局规则与参数校验 → 配置编译 → `scripts/powershell/06-舰艇海上巡逻.ps1` → 创建区域/航线/任务、分配舰艇并回读。潜艇不由此 Skill 控制。
