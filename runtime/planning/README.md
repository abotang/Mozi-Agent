# Agent 规划与校验

本目录把当前态势变成已注册 Skill 的调用参数，负责协议边界，不直接访问墨子写接口。

| 代码 | 作用 |
| --- | --- |
| `planner.py` | 先调用或复用联合方案，再并行评估空军、预警机、海军、陆军；空军输入包含空闲飞机及允许更新原任务的完整巡逻编组，排除预警机和干扰机；已占用巡逻机只可更新其原任务，主任务和护航 GUID 均限其 `own_units` |
| `plan_adapter.py` | 对含义明确的 LLM 字段别名和经纬度点列表做格式转换；不补造目标、单位或任务意图 |
| `validation.py` | 校验蓝方单元归属、接触目标类别、区域/航线、Skill 参数、GUID、重复分配和跨轮次飞机任务占用；原任务更新允许复用本任务飞机，产出 `SkillCall` |
| `__init__.py` | 包标记 |

输入是 `runtime/mozi/` 的当前态势、`rules/` 的触发与历史摘要，以及 `skills/` 注册的公开合同。输出经 `runtime/skills/compiler.py` 转为固定脚本配置。联合指挥只提总体任务意图；具体单位、目标、区域由专业 Agent 选择，并接受硬规则校验。航空战斗巡逻与预警区还要通过实时区域的相交/边界净距检查；更新原任务时将其旧区从比较中移除。专业 Agent 的规则与已有任务按 `rules/agent_context.py` 筛选，联合指挥保留全局信息。可选复评失败时保留首答并记录错误；复评成功后保留未被替换、单位不冲突的初稿调用，无打击调用的复评不覆盖原方案摘要。所有结果仍需通过完整参数校验。详细字段兼容规则见 `docs/PLAN_ADAPTER.md`。
